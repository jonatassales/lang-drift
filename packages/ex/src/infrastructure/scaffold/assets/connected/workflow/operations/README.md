# Operations — SDD adaptation

Documentary draft. Follows the [common SDD cycle](../README.md) and its [definition](../definition.json) in full. No executor or integration has been implemented.

Adaptations to discuss with operations/DevOps:

- During specification and preparation: expected change outcome, scope, permissions, impact, and reversibility.
- During execution: record authorized actions and relevant infrastructure checks.
- During verification, delivery, and observation: compare the outcome and environment signals with the defined criteria.
- Artifacts and connections: change plan/spec, execution records, and evidence; CI/CD, cloud, and inventory tools remain to be defined.

Skills and checkpoints will be domain-specific while preserving common phases, contracts, and traceability.
