# storage

The archive of the products: MinIO, the object store the `archive` consumer of `demo-requests` writes every event into, so a trimmed stream never loses a request's history. MinIO no longer publishes community images or binaries, so the Dockerfile builds it from its AGPL source at a pinned release. It is an infrastructure component, not a microservice: a Dockerfile and this README inside the `infra` package, so nothing but Docker builds it. Build and run it locally with `docker build -t langdrift-storage:local packages/infra/storage && docker run -d -p 9000:9000 -p 9001:9001 -e MINIO_ROOT_USER=… -e MINIO_ROOT_PASSWORD=… langdrift-storage:local`; the root credentials arrive at run time, never in the image. Under `dft` (spec 0032) it runs as the `storage` component, named after its folder (ADR 0004), and its `HEALTHCHECK` on `/minio/health/live` is the readiness probe.
