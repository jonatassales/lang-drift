# Getting Started

LangDrift is an agentic FinOps platform: it makes agent-assisted delivery accountable to a team budget, with Microruntimes as its engine. Start here to understand the platform, find the right reference, and run it locally.

## The product

| Part | The idea it serves |
| --- | --- |
| **LangDrift FinOps** | Make agent-assisted delivery accountable to a team budget, connecting product intent, delivery context, execution evidence and economic outcome in one inspectable chain. |
| **Microruntimes** | FinOps's engine: bounded, consumer-owned execution around software that already exists, planned and run by the `ex` CLI and its connected agent. |

The platform is served under `https://langdrift.md` and managed from the LangDrift console.

## Choose your path

- **Understand the platform:** read [Platform](/platform) for the one domain, the console and the principles the platform holds.
- **Bound agent-assisted delivery:** read [FinOps](/finops), then its [Concepts](/finops/concepts), [Architecture](/finops/architecture) and [CLI](/finops/cli).
- **Contribute:** use [Development](/development) for workspace commands, hooks and the review workflow.

## What is available today

| Surface | What you can do |
| --- | --- |
| Website | Read the platform site and the product pages, including illustrative product previews. |
| Documentation | Explore these docs: the platform, FinOps and the development workflow. |
| Console | Register projects from a local folder and supervise their microruntimes, with data from the local stub API. |
| `ex` CLI | Bootstrap a project, inspect native tools, administer the local cluster, and run the agent connected to the LangDrift console. |
| Design tokens and web package | Use the shared `@langdrift/tokens` stylesheets and the `@langdrift/web` components. |

The shell, the account and the runtime packages are planned, and the console reads a local stub API rather than a live service. Live cluster execution, a financial ledger and production integrations are not demonstrated.

## Run the platform locally

You need repository access, Git, Node.js **24 or newer** and **pnpm 12.4.2**. **Go 1.26+** is needed only to build the `ex` CLI.

```sh
git clone https://github.com/jonatassales/tao.git
cd tao
pnpm install
```

Installation installs the Git hooks and links the `drift` launcher. It does not install `ex` globally or modify shell profiles. See [Development](/development#hooks-and-review) for the checks those hooks perform.

## Open the docs

```sh
pnpm docs
```

Open `http://localhost:3002/docs`. Shared packages build before the docs start. Stop the foreground process when finished.

Documentation search uses an index generated by the production build. To verify search locally, build and serve the production docs as described in [Development](/development#build-and-serve-the-docs).
