# SRE — SDD adaptation

Documentary draft. Follows the [common SDD cycle](../README.md) and its [definition](../definition.json) in full. No executor or integration has been implemented.

Adaptations to discuss with SRE:

- During discovery and specification: observed signals, hypotheses, expected outcome, and reliability criteria agreed for the service.
- During preparation and execution: action scope, permissions, reversibility, and monitoring of relevant signals.
- During verification and observation: compare service behavior with the specification, including SLI/SLO when applicable, and record learning.
- Artifacts and connections: diagnosis, spec/action plan, evidence, and retrospective; observability and incident management tools remain to be defined.

Handling urgent situations within this cycle remains to be discussed. Skills and checkpoints will be domain-specific while preserving common contracts and traceability.
